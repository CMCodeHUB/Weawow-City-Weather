# Weawow Weather OS

Weawow Weather OS is an immersive, retro-styled weather application and interface featuring pixel art aesthetics, procedural city rendering, dynamic weather effects, and an integrated audio synthesizer[cite: 1].

---

## 🚀 Features

* **Retro Aesthetic**: Unique pixel-art styling (`pixel-art.css`) combined with a custom user interface design (`style.css`)[cite: 1].
* **City Engine**: Procedural cityscape generation (`city-engine.js`) that reacts to environmental shifts[cite: 1].
* **Dynamic Weather Effects**: Immersive weather FX system (`weather-fx.js`) and live weather data integration (`weather-api.js`)[cite: 1].
* **Audio Synthesizer**: Atmospheric audio generation (`audio-synth.js`) to match current weather moods[cite: 1].

---

🛠️ Getting Started
Clone or download this repository to your local machine.

Open the Weawow Weather OS/index.html file directly in any modern web browser to run the application.
